# AGENTS.md — 數位 IC 設計流程入門（LLM Wiki & HTML 簡報工作流）

## 1. 專案目標與需求摘要（先討論、後生成定案）
- **目標讀者**：對電機／半導體有興趣、但完全沒有晶片設計基礎的零基礎新手。
- **使用語言**：繁體中文，專有名詞首次出現時附英文原文（如 `邏輯合成（Logic Synthesis）`）。
- **頁面類型**：單一概念頁（`wiki/*.md`），固定包含「一句話白話定義、蓋智慧大樓比喻、核心運作與關鍵名詞、上下游關聯（至少 2 個 `[[連結]]`）、資料來源」。
- **出處細度**：每篇 Wiki 頁末必須明確標註對應的 `raw/0X_*.md`；每頁簡報必須標註對應的 `wiki/*.md`。
- **資料矛盾處理**：若不同 `raw/` 來源對數字或說法有差異（例如驗證佔比 50%～70%），必須如實並列區間並標註各自來源，禁止自行猜測或覆蓋。
- **Ingest 方式**：採「分批／逐篇 Ingest」，每完成一輪立刻執行 `git commit` 與 Lint 檢查，確保可追蹤修改（diff）。
- **後續產出**：以 `wiki/` 作為唯一事實來源（Single Source of Truth），產出 8～15 頁新手教學用單檔 HTML 簡報（`slides/index.html`）。

## 2. 目錄與狀態檔案規範（每一關的輸入／輸出皆為檔案）
- `raw/`：原始外部資料（唯讀，AI 絕對不可修改，且不可放入個資或機密文件）。
- `wiki/`：AI 消化整合後的概念頁。
- `index.md`：全站概念頁總目錄與摘要（每次 Ingest 必須同步更新）。
- `log.md`：記錄每次 Ingest、程式檢查與修正歷程。
- `slides/outline.md`：簡報大綱與「頁次 ↔ Wiki 頁面」對照表（供人工確認用）。
- `slides/index.html`：最終可瀏覽之教學型 HTML 簡報。
- `slides/report.md`：程式檢查與獨立 AI 審查的最終驗證報告。
- `check.py`：可執行的程式檢查腳本。

## 3. Graph 節點權限與退回規則（不能跳關、不能越權）
| 節點 | 只能看（Input） | 產出（Output） | 禁止事項（不可做） | 出錯退回目標 |
| :--- | :--- | :--- | :--- | :--- |
| **1. Ingest 寫入** | `raw/*.md`、`index.md` | `wiki/*.md`、`index.md`、`log.md` | 不可修改 `raw/`；不可寫入來源外的數據 | 重修該篇 `wiki/*.md` |
| **2. 檢索與大綱** | `index.md`、`wiki/*.md` | `slides/outline.md` | 相關 Wiki 頁少於 3 頁時不可硬湊 | 退回補檢索或停止 |
| **3. 人工確認** | `slides/outline.md` | 確認通過／修改意見 | 未經人工確認前不可直接寫 HTML | 退回修改 `outline.md` |
| **4. 渲染 HTML** | 已通過的 `outline.md` + 對應 `wiki/*.md` | `slides/index.html` | 不可引入 `wiki/` 以外的外部知識 | 只修出錯那一頁，不動其他頁 |
| **5. 驗證關卡** | `slides/index.html` + 引用的 `wiki/*.md` | `slides/report.md` | 檢查腳本與審查者不可直接偷改簡報 | 依錯誤類型局部退回 |

## 4. Loop 五要素與停止條件（剎車機制）
- **觸發**：使用者新增 `raw/` 資料，或指定主題要求生成簡報。
- **目標**：產出零斷鏈的 Wiki，以及 100% 忠於 Wiki 的教學 HTML 簡報。
- **限制**：`raw/` 唯讀；HTML 簡報頁數限制 8～15 頁；每頁必有 `Wiki 來源` 標註。
- **完成標準**：「做完了」不是 AI 說了算，必須同時通過：
  1. **程式檢查**：執行 `python check.py` 全數 PASS（Exit Code 0）。
  2. **獨立 AI 審查**：**開啟全新對話**（不帶生成過程上下文），僅提供 `slides/index.html` 與對應 `wiki/*.md`，檢查忠實度（有無講反／幻覺）與覆蓋率。
- **停止條件（剎車）**：
  - 單一節點局部修正 Loop **最多改 3 輪**；滿 3 輪仍未通過則立刻停手，輸出錯誤報告交由人工處理。
  - 若檢索後相關 Wiki 頁面 **少於 3 頁**，立刻停下並回報資料不足，嚴禁用模型自身知識硬湊。
